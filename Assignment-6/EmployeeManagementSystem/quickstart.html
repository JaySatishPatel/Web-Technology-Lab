🚀 Quick Start Guide

Get your Employee Management System up and running in 3 easy steps

Step 1: Start XAMPP Services

Launch XAMPP Control Panel

  • Open XAMPP Control Panel
  • Click "Start" next to Apache
  • Click "Start" next to MySQL
  • Wait for them to show "Running" (green indicator)
💡 Tip: XAMPP is usually located at C:\xampp\xampp-control.exe

Step 2: Import the Database

Create the database and tables

  1. Open your browser and go to http://localhost/phpmyadmin
  2. You should see the phpMyAdmin login page
  3. Click "Import" tab at the top
  4. Click "Choose File" and select database.sql from the EmployeeManagementSystem folder
  5. Click "Go" to import the database
✓ You should see a success message: "Import has been successfully finished"

Step 3: Access the Application

Open the Employee Management System

  1. Open your web browser
  2. Navigate to: http://localhost/EmployeeManagementSystem/
  3. You should see the employee management dashboard
✓ Your system is ready to use!

Troubleshooting

Common Issues and Solutions

❌ "404 Not Found"

Check that the URL is: http://localhost/EmployeeManagementSystem/

❌ "Connection failed"

Ensure MySQL is running in XAMPP Control Panel

❌ "Table doesn't exist"

Re-import the database.sql file in phpMyAdmin

❌ Database won't import

Try importing using the SQL tab instead of the Import tab
