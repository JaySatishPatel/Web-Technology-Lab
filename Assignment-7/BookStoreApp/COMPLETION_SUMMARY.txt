## 🚀 Quick Start Instructions

### Step 1: Install MySQL JDBC Driver (2 minutes)
```
1. Download from: https://dev.mysql.com/downloads/connector/j/
2. Extract: mysql-connector-java-8.0.x.jar
3. Copy to: C:\xampp\tomcat\lib\
```

### Step 2: Create Database (1 minute)
```sql
CREATE DATABASE bookstore;
USE bookstore;

CREATE TABLE ebookshop (
    book_id INT PRIMARY KEY AUTO_INCREMENT,
    book_title VARCHAR(100),
    book_author VARCHAR(100),
    book_price DOUBLE,
    quantity INT
);
```

### Step 3: Compile Java Files (1 minute)
**Windows Users:** Double-click `compile.bat` in WEB-INF/classes/

**Or manually:**
```bash
cd c:\xampp\tomcat\webapps\BookStoreApp\WEB-INF\classes\
javac -cp "c:\xampp\tomcat\lib\*" *.java
```

### Step 4: Start Application (1 minute)
```
1. Restart Apache Tomcat
2. Open: http://localhost:8080/BookStoreApp/
3. Start using the application!
```

**Total Setup Time: ~5 minutes**

## 🔧 Troubleshooting Quick Links

**Problem:** "Cannot find symbol" during compilation
- **Solution:** Ensure MySQL JDBC JAR is in `c:\xampp\tomcat\lib\`

**Problem:** "Connection refused" error
- **Solution:** Verify MySQL is running and credentials are correct in DBConnection.java

**Problem:** "404 Not Found" error
- **Solution:** Clear Tomcat work directory and restart Tomcat

**Problem:** "No database selected" error
- **Solution:** Ensure bookstore database exists in MySQL

**More Help:** See SETUP_CHECKLIST.txt for detailed troubleshooting
