# BookStore CRUD Web Application - Project Summary

## Project Created: Complete Servlet-Based Bookstore Management System

### What Has Been Created

#### 1. **Web Pages (HTML & JSP)**
- `index.html` - Home page with navigation to view and add books
- `addBook.html` - Form page for adding new books with all required fields
- `editBook.html` - Reference page for editing books

#### 2. **Java Servlets (WEB-INF/classes/)**

**a) DBConnection.java**
- Database connection management class
- Handles MySQL connectivity using JDBC
- Configuration: bookstore database with root user
- Modify credentials here if needed

**b) Book.java**
- Model/Entity class representing a Book
- Properties: book_id, book_title, book_author, book_price, quantity
- Includes getters and setters for all properties

**c) ViewBooksServlet.java**
- Endpoint: `/books` (GET)
- Lists all books from database in an HTML table
- Shows Edit and Delete action buttons for each book
- Displays book details: ID, Title, Author, Price, Quantity

**d) AddBookServlet.java**
- Endpoint: `/add` (POST)
- Handles form submission from addBook.html
- Validates all required fields
- Inserts new book into the database
- Provides success/error feedback

**e) EditBookServlet.java**
- Endpoint: `/edit?id=book_id` (GET)
- Retrieves specific book data
- Displays pre-filled edit form
- Connects to UpdateBookServlet for updates

**f) UpdateBookServlet.java**
- Endpoint: `/update` (POST)
- Handles book update operations
- Updates book_title, book_author, book_price, quantity
- Uses book_id to identify which book to update
- Provides success/error feedback

**g) DeleteBookServlet.java**
- Endpoint: `/delete?id=book_id` (GET)
- Handles book deletion
- Removes book from database by ID
- Includes JavaScript confirmation before deletion
- Provides success/error feedback

#### 3. **Configuration Files**
- `WEB-INF/web.xml` - Servlet mappings and configuration
- Already configured with all servlet mappings as required

#### 4. **Documentation & Scripts**
- `README.md` - Comprehensive setup guide
- `COMPILATION_GUIDE.txt` - Step-by-step compilation instructions
- `compile.bat` - Batch script for Windows users to compile all Java files
- `compile.sh` - Shell script for Linux/Mac users to compile Java files

## Quick Start Instructions

### For Windows (XAMPP):

1. **Install MySQL JDBC Driver:**
   ```
   Download: https://dev.mysql.com/downloads/connector/j/
   Extract and copy mysql-connector-java.jar to: C:\xampp\tomcat\lib\
   ```

2. **Create Database:**
   ```sql
   CREATE DATABASE bookstore;
   USE bookstore;
   CREATE TABLE ebookshop (
       book_id INT PRIMARY KEY AUTO_INCREMENT,
       book_title VARCHAR(100),
       book_author VARCHAR(100),
       book_price DOUBLE,
       quantity INT
   );
   ```

3. **Compile Java Files:**
   ```
   Navigate to: C:\xampp\tomcat\webapps\BookStoreApp\WEB-INF\classes\
   Double-click: compile.bat
   ```

4. **Start Application:**
   - Start Apache Tomcat from XAMPP Control Panel
   - Open: http://localhost:8080/BookStoreApp/
