## 📄 Page Descriptions

### 1. **Home Page** (`index.html`)
- **What it is:** Main landing page for the app
- **Features:**
  - Navigation bar with all main links
  - Hero section with gradient background
  - Feature cards describing the app
  - Call-to-action buttons
  - Links to: View Books, Add Book

**Navigation from here:**
- ✅ View All Books → ViewBooksServlet (GET /books)
- ✅ Add New Book → addBook.html
- ✅ Navigation menu → Any page

---

### 2. **Add Book Page** (`addBook.html`)
- **What it is:** Form to add new books to inventory
- **Features:**
  - Clean form layout with inputs for:
    - Book Title (text)
    - Author (text)
    - Price (number with $)
    - Quantity (number with units)
  - Add Book button (submits form)
  - Reset button (clears form)
  - Breadcrumb navigation
  - Quick links to other pages

**Form Submission:**
- Form Action: `action="add"` (AddBookServlet)
- Method: POST
- Validation: All fields required

**After Submission:**
- ✅ Success → Success Page with confirmation
- ❌ Error → Error message with "Go Back" link

**Navigation from here:**
- ✅ Back to Books List → ViewBooksServlet  
- ✅ Home → index.html
- ✅ Success → AddBookServlet Response

---

### 3. **View All Books Page** (Generated by `ViewBooksServlet`)
- **What it is:** Dynamic page showing all books in a table
- **Features:**
  - Table with columns:
    - Book ID (#)
    - Title
    - Author
    - Price (green badge)
    - Quantity (blue badge)
    - Actions (Edit/Delete buttons)
  - "Add New Book" button at top
  - Responsive table design
  - Row hover effects
  - "No Books Found" message if empty

**Action Buttons:**
- **Edit:** Links to `edit?id={book_id}` (EditBookServlet)
- **Delete:** Links to `delete?id={book_id}` with confirmation (DeleteBookServlet)

**Navigation from here:**
- ✅ Home → index.html
- ✅ Add Book → addBook.html
- ✅ Edit Book → EditBookServlet (GET request with id parameter)
- ✅ Delete Book → DeleteBookServlet (GET request with id parameter)

---

### 4. **Edit Book Page** (Generated by `EditBookServlet`)
- **What it is:** Form for editing existing book information
- **Features:**
  - Form pre-filled with current book data
  - Same fields as Add Book form
  - Hidden input for book ID
  - Update Book button
  - Reset button
  - Breadcrumb navigation
  - Back link to books list

**Form Submission:**
- Form Action: `action="update"` (UpdateBookServlet)
- Method: POST
- Data Passed:
  - id (hidden field)
  - title, author, price, qty (form inputs)

**After Submission:**
- ✅ Success → UpdateBookServlet Response (Success Page)
- ❌ Error → Error message with "Go Back" link

**Navigation from here:**
- ✅ Back to Books List → ViewBooksServlet
- ✅ Home → index.html
- ✅ Cancel (implicit) → Go back to books list

---

### 5. **Success Pages**
Different success pages for each operation:

**After Adding Book:**
- Icon: ✓ Check Circle (Green)
- Message: "Book Added Successfully!"
- Shows: Book title
- Next Steps:
  - View All Books
  - Add Another
  - Go Home

**After Updating Book:**
- Icon: ✓ Check Circle (Green)
- Message: "Book Updated Successfully!"
- Shows: Book title
- Auto-redirects to View All Books after 3 seconds
- Next Steps:
  - View All Books
  - Add Book
  - Go Home

**After Deleting Book:**
- Icon: 🗑️ Trash (Red)
- Message: "Book Deleted Successfully!"
- Shows: Book ID that was deleted
- Next Steps:
  - View All Books
  - Add Book
  - Go Home

## 📊 URL Mappings

| URL | servlet | Method | Purpose |
|-----|---------|--------|---------|
| `/` | Default | GET | Redirects to home |
| `/index.html` | None (HTML) | GET | Display home page |
| `/addBook.html` | None (HTML) | GET | Display add book form |
| `/editBook.html` | None (HTML) | GET | Info page (actual edit form is dynamic) |
| `/books` | ViewBooksServlet | GET | Display all books |
| `/add` | AddBookServlet | POST | Process add book form |
| `/edit?id=X` | EditBookServlet | GET | Display edit form for book X |
| `/update` | UpdateBookServlet | POST | Process update book form |
| `/delete?id=X` | DeleteBookServlet | GET | Delete book X |
| `/css/style.css` | None (CSS) | GET | Load custom styling |

## 🎯 User Journey Examples

### Journey 1: Adding a Book
```
1. User opens http://localhost:8080/BookStoreApp/
   → Lands on: index.html (Home Page)

2. User clicks "Add New Book" button
   → Navigates to: addBook.html (Form Page)

3. User fills form and clicks "Add Book"
   → Submits to: AddBookServlet (POST /add)

4. Servlet processes request
   → If successful: Shows success page
   → If failed: Shows error message

5. From success page, user clicks "View All Books"
   → Navigates to: ViewBooksServlet (GET /books)
   → Sees new book in the table!
```

### Journey 2: Editing a Book
```
1. User is viewing all books at ViewBooksServlet (/books)
   → Sees table of books with Edit/Delete buttons

2. User clicks "Edit" button for a book
   → Navigates to: EditBookServlet (GET /edit?id=5)

3. Servlet fetches book from database
   → Displays form pre-filled with book data

4. User updates fields and clicks "Update Book"
   → Submits to: UpdateBookServlet (POST /update)

5. Servlet updates database
   → Shows success page
   → Shows: "Book Updated Successfully!"

6. Page auto-redirects or user clicks "View All Books"
   → Back to: ViewBooksServlet (GET /books)
   → Updated book visible in table!
```

### Journey 3: Deleting a Book
```
1. User is viewing all books at ViewBooksServlet (/books)

2. User clicks "Delete" button
   → Browser shows confirmation dialog

3. If user confirms
   → Navigates to: DeleteBookServlet (GET /delete?id=5)

4. Servlet deletes book from database
   → Shows success page
   → Shows: "Book Deleted Successfully!"

5. User clicks "View All Books"
   → Back to: ViewBooksServlet (GET /books)
   → Book is no longer in the table!
```
