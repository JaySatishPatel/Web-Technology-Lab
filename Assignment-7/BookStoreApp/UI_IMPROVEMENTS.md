## 🚀 How to Use

### 1. **Navigate Between Pages**
- Use the navigation bar at the top to move between pages
- Use breadcrumbs to track your location
- Use quick action buttons to return to previous pages

### 2. **Add a Book**
- Click "Add Book" button on home page or navigation bar
- Fill in the form fields with book details
- Click "Add Book" to save
- You'll see a success message with options to view all books or add another

### 3. **View All Books**
- Click "View All Books" or "View Books" in navigation
- See all books in a beautiful table format
- Prices and quantities are highlighted in colored badges

### 4. **Edit a Book**
- Click the "Edit" button next to a book in the books list
- Update the book information
- Click "Update Book" to save changes
- Success page confirms the update

### 5. **Delete a Book**
- Click the "Delete" button next to a book
- Confirm the deletion in the dialog
- Success page confirms the deletion
