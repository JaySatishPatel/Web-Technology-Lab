# BookStore Application - Setup Checklist

## Pre-Requisites Installation
- [ ] Java Development Kit (JDK) 8+ installed
- [ ] Apache Tomcat 7.0+ installed (XAMPP includes this)
- [ ] MySQL Server installed and running
- [ ] Text editor or IDE ready

## Step 1: MySQL Database Setup
- [ ] Start MySQL Server
- [ ] Open MySQL command line or phpMyAdmin
- [ ] Copy and execute the SQL script below:

```sql
CREATE DATABASE bookstore;
USE bookstore;

CREATE TABLE ebookshop (
    book_id INT PRIMARY KEY AUTO_INCREMENT,
    book_title VARCHAR(100),
    book_author VARCHAR(100),
    book_price DOUBLE,
    quantity INT
);

-- Optional: Add sample data
INSERT INTO ebookshop (book_title, book_author, book_price, quantity) VALUES
('Java Programming', 'Herbert Schildt', 45.99, 10),
('Python for Beginners', 'Mark Lutz', 35.50, 15),
('Web Development', 'Jon Duckett', 54.99, 8);
```

- [ ] Verify table created successfully

## Step 2: Download MySQL JDBC Driver
- [ ] Visit: https://dev.mysql.com/downloads/connector/j/
- [ ] Download latest version (8.0+ recommended)
- [ ] Extract the JAR file
- [ ] Copy `mysql-connector-java-x.x.x.jar` to `c:\xampp\tomcat\lib\`
- [ ] For non-XAMPP: Copy to `TOMCAT_HOME\lib\`

## Step 3: Verify Database Credentials
- [ ] Open: `WEB-INF/classes/DBConnection.java`
- [ ] Verify/Update:
  - [ ] DATABASE_URL: `jdbc:mysql://localhost:3306/bookstore`
  - [ ] DATABASE_USER: `root` (or your username)
  - [ ] DATABASE_PASSWORD: `` (empty if default) or your password

## Step 4: Compile Java Files
### Option A: Use Batch Script (Windows)
- [ ] Navigate to: `c:\xampp\tomcat\webapps\BookStoreApp\WEB-INF\classes\`
- [ ] Double-click: `compile.bat`
- [ ] Wait for "Compilation SUCCESSFUL" message
- [ ] Press any key to close

### Option B: Manual Compilation
- [ ] Open Command Prompt
- [ ] Navigate to: `c:\xampp\tomcat\webapps\BookStoreApp\WEB-INF\classes\`
- [ ] Run:
  ```bash
  javac -cp "c:\xampp\tomcat\lib\*" *.java
  ```
- [ ] Verify all `.class` files are created

### Option C: Using IDE
- [ ] Create a Java project in your IDE
- [ ] Add MySQL JDBC JAR to build path
- [ ] Add Tomcat servlet-api.jar to build path
- [ ] Compile all Java files

## Step 6: Restart Tomcat

## Step 7: Test Application

- [ ] You should see the home page with buttons

## Troubleshooting Checklist

### Application Not Loading (404 Error)
- [ ] Verify Tomcat is running
- [ ] Check URL: `http://localhost:8080/BookStoreApp/`
- [ ] Clear Tomcat work directory and restart
- [ ] Check logs in `c:\xampp\tomcat\logs\catalina.log`

### Database Connection Error
- [ ] MySQL Server is running
- [ ] MySQL JDBC JAR is in `c:\xampp\tomcat\lib\`
- [ ] Database credentials correct in `DBConnection.java`
- [ ] Check `bookstore` database exists
- [ ] Restart Tomcat after making changes

### Compilation Errors
- [ ] Verify JDK path is correct
- [ ] MySQL JDBC JAR in classpath
- [ ] Tomcat servlet-api.jar available
- [ ] Re-run compile.bat or compile command
- [ ] Check for syntax errors in Java files

### "Cannot Find Symbol" Error during Compilation
- [ ] Ensure MySQL JDBC driver JAR is in lib directory
- [ ] Run compile command from correct directory
- [ ] Use full classpath: `javac -cp "c:\xampp\tomcat\lib\*" *.java`

### Port 3306 in use (MySQL)
- [ ] Check if another instance of MySQL is running
- [ ] Kill process using port 3306
- [ ] Restart MySQL in XAMPP

### Port 8080 in use (Tomcat)
- [ ] Check if another instance of Tomcat is running
- [ ] Update XAMPP port in server.xml (advanced)
- [ ] Kill process using port 8080
